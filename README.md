# Uber-Dashboard

Project Title
Uber Ride Analytics Dashboard – Power BI

📄 Short Description
An interactive Uber ride analytics dashboard built using Power BI to visualize key business metrics such as bookings, revenue, ride categories, distance analysis, customer ratings, and monthly trends. The dashboard helps stakeholders track performance, identify patterns, and make data-driven decisions.

🛠️ Tech Stack (with examples)
1. Power BI
Used for creating interactive dashboards
Visuals: Line charts, bar graphs, cards, donut charts, slicers

2. Excel / CSV (Data Manipulation)
Raw datasets stored in CSV/Excel files
Used for initial cleaning and formatting

3. Power Query (ETL)
Data cleaning (removing duplicates, formatting dates)
Merging data from multiple tables

4. DAX (Data Analysis Expressions)
Examples:
Total Revenue = SUM(Rides[Revenue])
Avg Distance = AVERAGE(Rides[Distance])
Monthly Booking = COUNT(Rides[Ride_ID])

📂 Data Source
Synthetic Uber ride dataset prepared for analysis from Kaggle

Includes fields such as:

Ride ID

Category (Auto, Bike, Mini, Sedan, XL)

Booking Status (Completed, Cancelled, Incomplete)

Distance

Pickup & Drop Locations

Driver Rating

Customer Rating

Monthly Revenues

Data stored in Excel/CSV format
